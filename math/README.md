# Matemática Discreta

Carpeta reservada para el componente de Matemática Discreta del proyecto integrador
(relaciones, grafos, red de flujo y algoritmo de Edmonds-Karp).

La implementación del algoritmo que usa la aplicación está en `backend/app/flujo.py`
y la pantalla **Red y flujo máximo** del frontend muestra el resultado y el corte mínimo.
