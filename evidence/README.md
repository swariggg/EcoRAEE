# Evidencias del avance

Carpeta para capturas de pantalla, videos y actas que respaldan las pruebas locales
(por ejemplo, la salida de `python -m pytest -v` y capturas de cada pantalla).

Las evidencias que se suben desde la aplicación no se guardan aquí: se guardan en
`backend/uploads/` (ignorado por git). En una fase posterior irán a Amazon S3.
